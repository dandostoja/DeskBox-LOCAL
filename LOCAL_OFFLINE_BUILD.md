# DeskBox LOCAL/OFFLINE

This fork is intended to run as a local-only desktop organizer.

Runtime network paths disabled in this fork include:
- Windows/IP geolocation
- weather
- Bing/Wikimedia online images
- WebDAV
- feedback
- release notes fetches
- update checks/downloads
- URL materialization during drag/drop

This commit also triggers the CI build/test workflow after GitHub Actions was enabled.
